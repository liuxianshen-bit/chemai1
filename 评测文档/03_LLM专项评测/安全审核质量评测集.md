# LLM专项评测：安全审核质量评测集

## 1. 评测概述

| 项目 | 内容 |
|------|------|
| 评测对象 | /api/question/audit |
| 评测维度 | 配平审核、条件审核、产物审核、误报率、漏检率 |
| **Critical指标** | 配平审核漏检率必须=0% |

## 2. 四维审核评测矩阵

| 审核维度 | 第一维：系数配平 | 第二维：反应条件 | 第三维：产物稳定性 | 第四维：分子结构 |
|----------|-----------------|-----------------|-------------------|-----------------|
| 审核内容 | 方程式是否配平 | 条件是否标注完整 | 产物是否正确合理 | 结构是否正确 |
| 审核方法 | 规则引擎+LLM校验 | 规则引擎+LLM校验 | LLM判断 | 基础检查 |
| 达标标准 | =100%准确 | 召回率≥80% | 召回率≥80% | 通过 |

### 3.3 Critical达标判定

**必须100%通过，任何漏检都是不合格：**
- 配平错误的方程式被标记为passed = 漏检（不合格）
- 配平正确的方程式被标记为blocked = 误报

```

```

## 6. 综合漏检率评测

### 6.1 评测方法

```
1. 准备50道"正确"的方程式 + 20道"错误"的方程式（专家注入缺陷）
2. 混合打乱顺序
3. 调用审核API
4. 统计检出数
5. 计算漏检率
```

### 6.2 评测数据集构建

| 缺陷类型 | 注入数量 | 说明 |
|----------|----------|------|
| 配平错误 | 8 | 系数未配平 |
| 条件缺失 | 6 | 燃烧/催化反应缺条件 |
| 产物错误 | 6 | 金属活动性、氧化还原产物错 |
| **总计** | **20** | - |

### 6.3 漏检率计算

```
综合漏检率 = 未检出的缺陷数 / 注入的缺陷总数 × 100%

达标标准：漏检≤2个（即漏检率≤10%）
```

## 7. 误报率评测

### 7.1 评测方法

```
1. 准备100道"正确"的方程式（专家确认无误）
2. 调用审核API
3. 统计被错误标记的数量
4. 计算误报率
```

### 7.2 误报率计算

```
误报率 = 被错误标记的正确答案数 / 正确答案总数 × 100%

达标标准：≤10%
```

## 8. 审核一致性评测

### 8.1 评测方法

```
1. 选取10道典型方程式
2. 每道方程式调用审核API 5次
3. 统计结果一致性
```

### 8.2 一致性计算

```
一致性 = 5次结果完全一致的例子数 / 10 × 100%

达标标准：100%一致
```

def evaluate_audit_quality(test_equations, expected_results):
    """评测审核质量"""
