## 3. 评测执行规范

### 3.1 评测指标计算

```
生成成功率 = 成功生成有效内容的请求数 / 总请求数 × 100%

空答率 = 返回空内容或拒绝回答的请求数 / 总请求数 × 100%

题目准确率 = 专家评审为"科学性正确"的题数 / 总题数 × 100%

知识点覆盖率 = 生成题目覆盖指定知识点的题数 / 指定知识点总数 × 100%

难度符合率 = 专家评审为"难度符合"的题数 / 总题数 × 100%

幻觉率 = 专家评审发现"存在事实性错误"的题数 / 总题数 × 100%
```

### 3.2 专家评审标准

每道题目由3名专家独立评审，投票决定最终结论：
- **通过**：至少2名专家认为题目科学性正确
- **不通过**：至少2名专家认为题目存在错误

### 3.3 评审检查清单

```
□ 知识点是否准确
□ 化学方程式是否配平
□ 反应条件是否正确
□ 产物是否合理
□ 选项是否只有一个正确
□ 选项是否具有区分度
□ 题目是否有歧义
□ 答案是否正确
□ 陷阱选项是否合理
□ 语言表述是否清晰
```
