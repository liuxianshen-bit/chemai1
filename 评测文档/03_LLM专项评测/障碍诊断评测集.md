# LLM专项评测：障碍诊断评测集

## 1. 评测集概述

| 项目 | 内容 |
|------|------|
| 评测对象 | /api/diagnosis/* |
| 评测维度 | 诊断准确率、干预建议有效率、诊断一致性 |
| 达标标准 | 诊断准确率≥60%（老师接受率）、干预建议有效率≥70% |

## 2. 障碍类型定义（根据PRD v1.0）

| 障碍类型 | 定义 | 判断条件（默认，可配置） |
|----------|------|------------------------|
| **概念理解型** | 学生对化学概念的理解存在偏差，导致解题错误 | 同一知识点连续错误≥3次 |
| **审题障碍型** | 学生读取题目信息不全，或对题目条件的理解有误 | 同一知识点连续错误≥2次 |
| **表述障碍型** | 学生理解正确答案，但无法规范表述 | 同一知识点连续错误≥3次 |

## 4. 评测执行规范

### 4.1 评测流程

```
1. 准备90例障碍诊断测试数据（每类30例）
2. 调用 /api/diagnosis/barrier/{class_id}/{exam_record_id}
3. 获取AI诊断结果
4. 对比专家标注的预期结果
5. 计算诊断准确率和干预建议有效率
```

### 4.2 评测指标计算

```
诊断准确率 = AI诊断结果与专家判断一致的案例数 / 总案例数 × 100%

干预建议有效率 = 老师评价"有用"的建议数 / 总建议数 × 100%

诊断一致性 = 同一学生诊断5次，结果完全一致的比例 × 100%
```
