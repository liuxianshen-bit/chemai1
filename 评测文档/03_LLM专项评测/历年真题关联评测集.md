## 4. 评测维度详解

### 4.1 关联准确率

**评测方法：**
```
1. 生成100道测试题目
2. 调用关联API获取关联真题
3. 3名专家独立评估每道题的关联是否合理
4. 计算多数投票的准确率
```

**达标标准：≥85%**

### 4.2 关联召回率

**评测方法：**
```
1. 对每个知识点，专家列出最相似的5道历年真题
2. 调用关联API
3. 统计系统找出的真题与专家列表的重叠数
4. 计算召回率
```

**计算公式：**
```
召回率 = 系统找出的重叠真题数 / 专家列出的真题数 × 100%

达标标准：≥60%
```

### 4.3 相似度计算准确性

**评测方法：**
```
1. 准备20对相似/不相似的题目对
2. 获取系统计算的相似度
3. 对比与专家判断的偏差
```

**达标标准：偏差≤15%**

### 4.4 差异提示有效性

**评测方法：**
```
1. 准备50道系统标注"有差异"的新题
2. 获取差异提示内容
3. 专家评估差异提示是否有价值
```

**达标标准：≥75%有用**
