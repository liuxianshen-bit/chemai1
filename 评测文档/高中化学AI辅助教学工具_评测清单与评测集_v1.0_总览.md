## 2. 大模型核心评测指标

### 2.1 评测指标定义

| 指标名称 | 定义 | 计算公式 | 达标值 |
|----------|------|----------|--------|
| **准确率 (Accuracy)** | 正确判断数 / 总样本数 | TP+TN / (TP+TN+FP+FN) | ≥ 85% |
| **召回率 (Recall)** | 正确检出数 / 应检出总数 | TP / (TP+FN) | ≥ 80% |
| **精确率 (Precision)** | 正确检出的正确数 / 检出总数 | TP / (TP+FP) | ≥ 80% |
| **空答率 (No-Response Rate)** | 模型拒绝回答或返回空的占比 | 空回答数 / 总请求数 | ≤ 5% |
| **生成成功率 (Generation Success Rate)** | 成功生成有效内容的占比 | 有效生成数 / 总请求数 | ≥ 95% |
| **幻觉率 (Hallucination Rate)** | 生成错误/无意义内容的占比 | 错误内容数 / 总生成数 | ≤ 10% |
| **审核漏检率 (Miss Rate)** | 审核未发现问题的占比 | 漏检数 / 问题总数 | ≤ 2% |
| **配平准确率 (Balance Accuracy)** | 化学方程式配平正确的占比 | 配平正确数 / 审核总数 | = 100% |

### 2.2 大模型评测上下文矩阵

| 任务类型 | 输入 | 期望输出 | LLM依赖度 |
|----------|------|----------|-----------|
| AI出题 | 知识点+难度+数量 | 题目+选项+答案 | 高 |
| 题目审核 | 题目内容 | 审核结果+问题列表 | 高 |
| 障碍诊断 | 学生答题历史 | 障碍类型+干预建议 | 高 |
| 历年真题关联 | 题目内容+知识点 | 相似真题列表 | 高 |
| 答案判定 | 学生答案+标准答案 | 对/错+解析 | 中 |
| 自适应难度评估 | 学生历史表现 | 推荐难度 | 高 |
