# 化学方程式反应条件审核测试集

## 1. 测试集概述

| 项目 | 内容 |
|------|------|
| 测试目的 | 验证化学方程式审核引擎对反应条件的检测能力 |
| 审核维度 | 第二维：反应条件标注 |
| 验收标准 | 条件缺失检出率≥80% |

## 2. 常见反应条件清单

| 条件类型 | 关键词 | 适用反应 |
|----------|--------|----------|
| 点燃 | 点燃 | 可燃物燃烧（CH₄、C₂H₅OH、S、P、Fe等） |
| 加热 | △, 加热 | 分解反应（KClO₃、KMnO₄等） |
| 高温 | 高温 | 煅烧、碳还原（CaCO₃、Fe₂O₃等） |
| 催化剂 | MnO₂, Cu, Fe, 催化剂 | 催化反应（H₂O₂分解、KClO₃分解） |
| 浓硫酸 | 浓H₂SO₄ | 钝化、脱水（Cu、HNO₃反应） |
| 稀硫酸 | 稀H₂SO₄ | 金属反应 |
| 浓盐酸 | 浓HCl | 实验室制氯气 |
| 稀硝酸 | 稀HNO₃ | 金属与酸反应 |
| 浓硝酸 | 浓HNO₃ | 钝化 |
| 光照 | 光照 | 光化反应 |
| 电解 | 电解, 通电 | 电解反应 |
| 压强 | 高压 | 反应条件标注 |

## 4. 测试执行规范

### 4.1 测试流程

```
1. 准备测试数据集（20个需条件的 + 15个正确标注的）
2. 对每个方程式调用审核API
3. 检查condition_audit.status和conditions_found字段
4. 记录缺失条件的检出情况
```

### 4.2 检出率计算

```
条件缺失检出率 = 被正确标记warning的方程式数 / 应标记的方程式总数 × 100%
```
