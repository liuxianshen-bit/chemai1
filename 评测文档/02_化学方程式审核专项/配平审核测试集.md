## 3. 测试执行规范

### 3.1 测试流程

```
1. 准备测试数据集（25通过 + 25失败 + 8复杂 = 58题）
2. 对每个方程式调用审核API
3. 记录返回的coefficient_audit.status
4. 对比预期结果与实际结果
5. 计算准确率 = 正确判断数 / 58
```

### 3.2 通过判定

**配平审核通过条件（必须100%满足）：**
- ✅ 所有PASS案例：coefficient_audit.status = "passed"
- ❌ 所有FAIL案例：coefficient_audit.status = "blocked"
- ✅ 所有COMP案例：正确识别

**漏检定义：**
- FAIL案例被标记为passed/warning = 漏检
- 必须0漏检

## 5. 附录：常见配平错误类型

| 错误类型 | 示例 | 说明 |
|----------|------|------|
| 系数遗漏 | CH₄ + O₂ = CO₂ + H₂O | O₂前应加2，H₂O前应加2（正确：CH₄ + 2O₂ = CO₂ + 2H₂O） |
| 系数多余 | 2Na + Cl₂ = 2NaCl | 正确，无需修改 |
| 下标错误 | H₂O₂ = H₂O + O | O₂前应加系数 |
| 产物错误 | Na + HCl = NaCl + H | 产物应为H₂ |
| 条件缺失 | Fe + O₂ → Fe₃O₄ | 缺"点燃"条件 |
| 气体符号 | CO₂ + H₂O = H₂CO₃ | 碳酸不稳定应标注 |
