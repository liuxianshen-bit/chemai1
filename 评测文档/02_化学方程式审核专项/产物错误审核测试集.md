# 化学方程式产物错误审核测试集

## 1. 测试集概述

| 项目 | 内容 |
|------|------|
| 测试目的 | 验证化学方程式审核引擎对产物正确性的检测能力 |
| 审核维度 | 第三维：产物稳定性判断 |
| 验收标准 | 产物错误检出率≥80% |

## 3. 测试执行规范

### 3.1 检出率计算

```
产物错误检出率 = 被正确标记blocked/warning的方程式数 / 应标记的方程式总数 × 100%
```

## 4. 常见产物错误类型

| 错误类型 | 示例 | 说明 |
|----------|------|------|
| 金属活动性顺序错误 | Cu + HCl → CuCl₂ + H₂ | 铜在氢后不反应 |
| 酸的条件错误 | C + O₂ → CO | 氧气充足生成CO₂ |
| 产物状态错误 | Na + HCl → NaCl + H | H应为H₂ |
| 氧化还原产物错误 | Fe + HCl → FeCl₃ + H₂ | 铁与盐酸生成FeCl₂ |
| 不稳定产物未分解 | H₂CO₃ → H₂O + CO₂ | 应写分解产物 |

|------|--------|------------|

| 误报率 | ≤10% | P1 |
