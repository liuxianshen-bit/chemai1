# 性能基准测试方案

## 1. 测试概述

| 项目 | 内容 |
|------|------|
| 测试目的 | 验证系统性能是否满足PRD定义的非功能需求 |
| 测试依据 | PRD v1.0 第9.1节 性能要求 |

## 2. 性能指标要求

| 指标 | 要求（内测低并发） | 测试方法 |
|------|-------------------|----------|
| API响应时间(P95) | ≤1秒 | 1000次请求统计 |
| 首屏加载时间 | ≤3秒 | 实际测量 |
| 并发用户(教师端) | ≤5人同时在线 | 5人同时操作 |
| 并发用户(学生端) | ≤200人同时在线 | 200人同时在线 |
| 系统可用性 | ≥99%(月度) | 30天监控 |
| OCR识别+统计时间 | ≤15分钟(90人班) | 实际计时 |
| 单题审核时间 | ≤3秒 | 100次测试 |
| 单学生诊断时间 | ≤5秒 | 100次测试 |
| 面板加载时间 | ≤3秒 | 10次测试 |

## 6. 附录：locust并发测试脚本示例

```python
from locust import HttpUser, task, between

class TeacherUser(HttpUser):
    wait_time = between(1, 3)

    @task(3)
    def generate_questions(self):
        self.client.post("/api/question/generate", json={
            "knowledge_points": ["盐类水解"],
            "difficulty": "medium",
            "quantity": 10
        })

    @task(2)
    def audit_question(self):
        self.client.post("/api/question/audit", json={
            "question_content": "下列关于盐类水解的说法正确的是"
        })

class StudentUser(HttpUser):
    wait_time = between(1, 2)

    @task(3)
    def get_practice(self):
        self.client.get("/api/practice/student/202401001/tasks")

    @task(2)
    def submit_practice(self):
        self.client.post("/api/practice/submit", json={
            "practice_id": "practice_001",
            "student_id": "202401001",
            "answers": [{"question_id": "q1", "answer": "A"}]
        })
```
