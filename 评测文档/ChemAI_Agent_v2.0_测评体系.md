## 2. 测评指标体系

### 2.1 LLM 核心评测指标

| 指标名称 | 定义 | 计算公式 | 达标值 | 评测频率 |
|---------|------|---------|--------|---------|
| **准确率 (Accuracy)** | 正确判断数 / 总样本数 | (TP+TN) / (TP+TN+FP+FN) | ≥85% | 每评测集 |
| **召回率 (Recall)** | 正确检出数 / 应检出总数 | TP / (TP+FN) | ≥80% | 每评测集 |
| **精确率 (Precision)** | 正确检出的正确数 / 检出总数 | TP / (TP+FP) | ≥80% | 每评测集 |
| **空答率 (No-Response)** | 模型拒绝回答或返回空的占比 | 空回答数 / 总请求数 | ≤5% | 每次请求 |
| **生成成功率** | 成功生成有效内容的占比 | 有效生成数 / 总请求数 | ≥95% | 每次请求 |
| **幻觉率 (Hallucination)** | 生成错误/无意义内容的占比 | 错误内容数 / 总生成数 | ≤10% | 每评测集 |
| **一致性 (Consistency)** | 同一输入多次生成结果的一致性 | 一致次数 / 总测试次数 | ≥80% | 每评测集 |

### 2.2 化学专业评测指标

| 指标名称 | 定义 | 计算公式 | 达标值 | 评测频率 |
|---------|------|---------|--------|---------|
| **配平准确率** | 化学方程式配平正确的占比 | 配平正确数 / 审核总数 | =100% | 每次审核 |
| **条件完整性率** | 反应条件标注完整的占比 | 完整数 / 审核总数 | ≥95% | 每次审核 |
| **产物正确率** | 产物符合化学规律的占比 | 正确数 / 审核总数 | ≥95% | 每次审核 |
| **结构合理率** | 分子结构简式正确的占比 | 合理数 / 审核总数 | ≥90% | 每次审核 |
| **审核漏检率** | 审核未发现问题的占比 | 漏检数 / 问题总数 | ≤2% | 每评测集 |
| **审核误报率** | 正确题目被错误标记的占比 | 误报数 / 正确总数 | ≤10% | 每评测集 |
