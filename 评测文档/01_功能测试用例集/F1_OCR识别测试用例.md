## 4. 大模型相关评测（F1）

### 4.1 OCR后处理质量评测

| 评测ID | F1-LLM-001 | 评测类型 | LLM专项 |
|--------|------------|----------|---------|
| 评测内容 | OCR后处理质量 | 评测方法 | 随机抽取100张识别结果，人工校验 |
| 达标标准 | 准确率≥95% | 当前状态 | ☐ 待评测 |

**评测步骤：**
1. 准备100张标准答题卡图片
2. 调用OCR识别API
3. 人工对比识别结果与标准答案
4. 计算准确率 = 正确识别数 / 100

### 6.1 ExamStatsRequest 示例

```json
{
  "class_id": "class_2024高二化学01",
  "exam_name": "高二上月考化学",
  "questions": [
    {
      "number": "1",
      "knowledge_points": ["电解质溶液"],
      "max_score": 5
    },
    {
      "number": "2",
      "knowledge_points": ["离子反应", "离子方程式"],
      "max_score": 5
    }
  ],
  "ocr_results": [
    {
      "student_id": "202401001",
      "student_name": "张三",
      "answers": {"1": "A", "2": "B"},
      "scores": {"1": 5, "2": 0}
    }
  ]
}
```
