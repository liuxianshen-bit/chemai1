## 两套评测体系的关系

| 维度 | 旧功能模块评测 (v1.0/v2.0) | 新 14 维度轨迹评测 |
|------|--------------------------|-------------------|
| **评测视角** | 功能模块（F1-F7）：输出质量 | 行为维度（14维）：轨迹正确性 |
| **评测方法** | 黑盒测试 + LLM 指标（准确率/召回率/幻觉率） | 轨迹断言（tool_called / route / trajectory_order） |
| **评测粒度** | 端到端功能场景 | 逐步骤行为验证 |
| **核心理念** | "产出对不对" | "行为对不对" |
| **适用阶段** | 功能验证、验收测试 | 开发护栏、CI 门禁、回归检测 |

**两者互补，不替代。** 旧文档是"原材料"（提供测试输入和期望输出），新 EVALS 是"加工框架"（将测试数据转化为可自动化执行的轨迹断言）。

## 版本说明

- **v1.0** (2026-04-07): 按 F1-F7 功能模块组织的黑盒评测体系，含 8 项 LLM 核心指标
- **v2.0** (2026-04-14): 新增 Chem Skills + Agent 协同评测维度，补充自改进系统评测
- **14-dim** (2026-06-30): 业界标准的 14 维度轨迹评测体系，对接 LangGraph 四层架构 + 六维轨迹框架 + Google Cloud 三支柱

v1.0 和 v2.0 的模块评测文档继续保留作为"原材料仓库"。新 EVALS 场景从这些文档中提取测试数据，转化为可自动化执行的轨迹断言。
