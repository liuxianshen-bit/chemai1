## 二、登录与权限验证机制

### 2.1 登录流程
```python
# 伪代码
@app.route('/api/auth/login', methods=['POST'])
def login():
    username = request.json['username']
    password = request.json['password']

    user = User.authenticate(username, password)

    if not user:
        return {'success': False, 'error': '账号或密码错误'}

    # 生成JWT
    token = jwt.encode({
        'user_id': user.id,
        'role': user.role,
        'school_id': user.school_id,
        'exp': datetime.utcnow() + timedelta(days=7)
    }, SECRET_KEY)

    # 根据角色返回不同跳转地址
    redirect_urls = {
        'admin': '/admin.html',           # 管理后台
        '教务管理员': '/admin.html',
        '学科组长': '/teacher.html',     # 教师后台（带学科管理）
        'teacher': '/teacher.html',       # 普通教师后台
        'student': '/student.html'       # 学生端
    }

    return {
        'success': True,
        'token': token,
        'role': user.role,
        'name': user.name,
        'redirect_url': redirect_urls.get(user.role, '/student.html')
    }
```

### 2.2 JWT验证中间件
```python
# 每个API请求都要验证JWT
def verify_token(token):
    try:
        payload = jwt.decode(token, SECRET_KEY, algorithms=['HS256'])
        return payload
    except ExpiredSignatureError:
        return None  # token过期
    except InvalidTokenError:
        return None  # token无效

# 请求示例
GET /api/students
Headers: {
    'Authorization': 'Bearer <jwt_token>'
}

# 中间件处理
def require_auth(f):
    @wraps(f)
    def decorated(*args, **kwargs):
        token = request.headers.get('Authorization', '').replace('Bearer ', '')
        payload = verify_token(token)

        if not payload:
            return {'error': '未登录或token无效'}, 401

        # 将用户信息注入request
        request.user_id = payload['user_id']
        request.user_role = payload['role']
        request.school_id = payload['school_id']

        return f(*args, **kwargs)
    return decorated
```

### 2.3 角色权限定义
```python
# 权限配置
ROLE_PERMISSIONS = {
    'admin': {
        # 全部权限
        'school': ['create', 'read', 'update', 'delete'],
        'grade': ['create', 'read', 'update', 'delete'],
        'class': ['create', 'read', 'update', 'delete'],
        'teacher': ['create', 'read', 'update', 'delete'],
        'student': ['create', 'read', 'update', 'delete'],
        'assignment': ['create', 'read', 'update', 'delete'],
        'analysis': ['read'],  # 只读
    },

    '教务管理员': {
        'school': ['read'],      # 只读学校信息
        'grade': ['create', 'read', 'update'],  # 不能删除年级
        'class': ['create', 'read', 'update', 'delete'],
        'teacher': ['read', 'update'],  # 不能创建删除教师
        'student': ['create', 'read', 'update', 'delete'],
        'assignment': ['create', 'read', 'update', 'delete'],
        'analysis': ['read'],
    },

    '学科组长': {
        'school': ['read'],
        'grade': ['read'],
        'class': ['read'],  # 只能看本学科班级
        'teacher': ['read'],  # 只能看本学科教师
        'student': ['read'],  # 只能看本班学生
        'assignment': ['create', 'read', 'update'],
        'analysis': ['read'],
    },

    'teacher': {
        'school': ['read'],
        'grade': ['read'],
        'class': ['read'],  # 只能看任课班级
        'teacher': ['read'],  # 只能看自己
        'student': ['read'],  # 只能看任课班级学生
        'assignment': ['create', 'read', 'update'],  # 只能管自己布置的
        'analysis': ['read'],  # 只能看自己班级的
    },

    'student': {
        'self_data': ['read'],  # 只能看自己的
        'assignment': ['read'],  # 只能看自己的作业
        'grade': ['read'],
    }
}
```

## 八、认证机制详细设计

### 8.1 登录安全机制
```
登录流程:
1. 输入账号+密码 → POST /api/auth/login
2. 后端验证:
   - 校验账号存在且状态正常
   - 校验密码（ bcrypt 加密比对）
   - 校验登录尝试次数（5分钟内限5次，超限锁定15分钟）
3. 颁发JWT:
   - Access Token: 有效期1小时
   - Refresh Token: 有效期7天（存储在httpOnly cookie）
4. 返回: { token, user, redirect_url }

Token刷新:
- 前端在access token过期前10分钟自动调用 /api/auth/refresh
- 用refresh token换取新的access token
- 登出时同时清除两种token
```

### 8.2 密码安全
```
要求:
- 长度 ≥ 8位
- 必须包含字母和数字
- 教师首次登录强制修改密码
- 密码不允许与最近5次相同
- 支持手机号+验证码找回密码
```

## 十一、关键设计决定

1. **一套系统，动态菜单** - admin.html和teacher.html合并为一个，根据role动态显示菜单
2. **数据实时同步** - 管理端操作后，教师端下次刷新可见
3. **班级是核心** - 教师的所有权限都基于"任教班级+科目"
4. **现有功能不改** - OCR、诊断等功能只加数据来源绑定，不改核心逻辑
5. **批量操作优先** - 支持Excel导入导出，减少手工操作
