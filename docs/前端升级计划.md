# ChemAI 前端升级计划

**生成日期**: 2026-04-21
**版本**: v1.0

---

## 一、升级目标

将现有前端升级为包含完整功能的版本，参考早期版本的交互设计，集成后端已实现的智能文档解析能力。

## 四、详细实施计划

### 4.1 第一阶段：考试管理重构（P0）

#### 修改文件: `frontend/src/modules/teacher/exam.js`

**目标**: 重构考试管理页面，新增选题功能Tab

**新增的Tab结构**:
```
┌─────────────────────────────────────────────────────────┐
│  📝 AI生成题目   📚 手动选题    📤 导入真题               │
├─────────────────────────────────────────────────────────┤
│                                                          │
│  【内容区域，根据Tab显示不同内容】                         │
│                                                          │
└─────────────────────────────────────────────────────────┘
```

**Tab 1: AI生成题目**（保持现有功能）
- 现有 `question.js` 的生成题目逻辑
- 调用 `TaskType.GENERATE_QUESTIONS`
- ChemAI Agent 会自动检索历年真题作为RAG参考

**Tab 2: 手动选题**（新增）

布局：左栏筛选 + 中栏真题列表 + 右栏已选题目

┌──────────┬────────────────────────┬────────────────┐
│ 筛选条件  │ 真题列表                │ 已选题目        │

│ 来源      │ ┌────────────────────┐│ 共 N 题        │

│          │ │ 知识点: 氧化还原 │ │ [题目卡片]      │
│ 年份      │ │ 难度: 中等       │ │ [题目卡片]      │
│ [全部 ▼] │ └────────────────────┘│                │
│          │ ┌────────────────────┐│ [清空] [加入]  │
│ 知识点    │ │ 📄 2023全国卷    │ │                │
│ [全部 ▼] │ └────────────────────┘│                │
│          │                        │                │
│ 难度      │                        │                │
│ ○全部    │                        │                │
│ ○基础    │                        │                │
│ ○中等    │                        │                │
│ ○困难    │                        │                │

**核心逻辑**:
```javascript

GET /api/exam-bank/exam-sets

  &year=xxx
  &knowledge_point=xxx
  &difficulty=xxx

// 调用考试创建API，将选中的历年真题ID传入
```

**Tab 3: 导入真题**（新增）

流程：
```
Step 1: 选择文件（支持拖拽）
        ↓
Step 2: 调用智能解析API
        POST /api/ocr/parse/document
        {
          "file_data": "base64...",
          "file_type": "auto",
          "source": "auto"
        }
        ↓
Step 3: 显示解析结果预览
        ↓
Step 4: 选择目标真题集
        POST /api/exam-bank/format-questions
        ↓
Step 5: 确认导入
        POST /api/exam-bank/import-questions
```

## 六、API调用汇总

### 6.1 新增调用的API

| API | 方法 | 用途 |
|-----|------|------|
| `/api/exam-bank/exam-sets` | GET | 获取真题集列表 |
| `/api/exam-bank/exam-sets` | POST | 创建真题集 |
| `/api/exam-bank/exam-sets/{set_id}` | GET | 获取真题集详情 |
| `/api/exam-bank/historical` | GET | 查询历年真题 |
| `/api/exam-bank/format-questions` | POST | 格式化OCR结果为题目 |
| `/api/exam-bank/import-questions` | POST | 导入题目到真题集 |
| `/api/ocr/parse/document` | POST | 统一文档解析入口 |
| `/api/ocr/services/status` | GET | 获取服务可用性状态 |

### 6.2 智能解析调用示例

```javascript
// 上传真题时调用智能解析
async function smartParseDocument(fileData, fileType = 'auto') {
  const response = await fetch('/api/ocr/parse/document', {
    method: 'POST',
    headers: { 'Content-Type': 'application/json' },
    body: JSON.stringify({
      file_data: fileData,  // base64编码
      file_type: fileType,  // "auto", "pdf", "image"
      source: "auto"         // "auto", "ocr", "mineru", "vision"
    })
  });
  return response.json();
}
```

### 6.3 服务状态调用示例

```javascript
// 获取服务状态
async function getServicesStatus() {
  const response = await fetch('/api/ocr/services/status');
  return response.json();
  // 返回: {ocr: {...}, mineru: {...}, vision: {...}}
}
```

## 七、交互状态定义

### 7.1 手动选题Tab状态

| 状态 | 说明 |
|------|------|
| 空状态 | 暂无真题集，显示"创建自定义真题集"按钮 |
| 加载中 | 显示loading动画 |
| 已加载 | 显示真题集列表 |
| 已选题目 | 右栏显示已选题目数量和列表 |

### 7.2 导入真题Tab状态

| 状态 | 说明 |
|------|------|
| 空状态 | 显示拖拽上传区域 |
| 上传中 | 显示上传进度 |
| 解析中 | 显示"正在智能解析..."+当前使用的解析方式 |
| 解析成功 | 显示提取到的题目数量和预览 |
| 解析失败 | 显示错误信息+重试按钮 |
| 导入中 | 显示导入进度 |
| 导入成功 | 显示成功提示 |

### 7.3 服务状态Tab状态

| 状态 | 说明 |
|------|------|
| 检测中 | 显示loading |
| 全部可用 | 三个服务都显示✅ |
| 部分可用 | 可用的显示✅，不可用的显示❌ |
| 全部不可用 | 显示❌+错误提示 |

## 八、错误处理

### 8.1 手动选题错误

| 错误 | 处理方式 |
|------|----------|
| 获取真题集失败 | Toast提示"加载失败"，显示重试按钮 |
| 筛选无结果 | 显示"暂无符合条件的真题" |
| 加入试卷失败 | Toast提示"加入失败" |

### 8.2 导入真题错误

| 错误 | 处理方式 |
|------|----------|
| 文件格式不支持 | Toast提示"不支持的文件格式" |
| 解析失败 | 显示"解析失败"，提供重试按钮，可切换手动输入 |
| 导入失败 | Toast提示"导入失败"，保留预览数据可重试 |

### 8.3 服务状态错误

| 错误 | 处理方式 |
|------|----------|
| 获取状态失败 | 显示"检测失败"，提供重试按钮 |
| 服务不可用 | 显示❌+原因（未配置/连接失败等） |
