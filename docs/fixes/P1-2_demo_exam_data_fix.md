## 问题描述
`init_db.py` 只创建了基础数据（学校/年级/教师/班级/学生/账号），未创建考试记录、题目、学生作答、障碍诊断配置等业务数据，导致教师端面板、错题报告、诊断、学情分析均显示"无数据"。

## 修改内容

### 1. `data/demo_exam_data.sql`（新增）
15 道高中化学题目的 SQL 数据文件，可直接用 `sqlite3` 命令行执行：
- 2 场考试记录（高一1班 + 高一2班）
- 15 道选择题（含选项、答案、解析、知识点、难度）
- 2 条障碍诊断配置（海老师 + 刘老师）

### 2. `app/utils/init_db.py`

**`load_sql_file()`** — 新增函数，加载 SQL 文件内容

**`create_demo_exam_data(db)`** — 重写：
- 执行 SQL 文件加载基础数据（题目、考试框架、障碍配置）
- 为高一(2)班复制一套题目（`demo_q2_*` ID）
- 为 67 名学生生成随机作答（配置每道题的错误率）
  - 高一(1)班：34人 × 15题 = 510 条
  - 高一(2)班：33人 × 15题 = 495 条
  - 合计：1005 条作答记录
- 统计每场考试的正确率和错题分布
- 创建两位老师的障碍诊断配置

**数据源拆分：**
- 静态基础数据 → `data/demo_exam_data.sql`（SQL 文件）
- 动态生成逻辑（随机作答、统计计算）→ Python 代码
