# ChemAI 功能与界面完整梳理

## 一、系统定位

ChemAI 是一个高中化学 AI 辅助教学系统，支持：
- **Web 前端**：教师端、学生端、家长端
- **ChemAI Agent 集成**：通过 MCP 协议连接外部 Agent（Telegram/Discord）
- **核心能力**：OCR识别、智能出题、障碍诊断、错题强化、间隔复习、学情预警

---

## 二、前端页面结构

### 2.1 教师端 (teacher_v2.html)

| 页面 | 路由 | 核心功能 | 调用的后端模块 |
|------|------|----------|----------------|
| **首页/OCR** | `/teacher.html` | 上传答题卡图片、OCR识别、自动批改 | `/api/ocr/*` |
| **考试管理** | `/teacher.html#exam` | 创建考试、查看成绩、导出统计 | `/api/exam/*` |
| **题目管理** | `/teacher.html#question` | 题库管理、AI出题、真题检索 | `/api/question/*`, `/api/exam-bank/*` |
| **障碍诊断** | `/teacher.html#diagnosis` | 班级障碍分析、学生障碍详情、生成学习计划 | `/api/diagnosis/*` |
| **报告生成** | `/api/report/*` | 生成班级/学生报告、查看历史报告 | `/api/report/*` |
| **学生管理** | `/teacher.html#students` | 学生列表、查看学生详情、预警学生 | `/api/users/*`, `/api/warning/*` |
| **数据大盘** | `/teacher.html#analytics` | 班级学情概览、排名、障碍分布、热力图 | `/api/analytics/*` |

**入口**：侧边栏导航

## 三、MCP 工具与前端功能对应

| MCP 工具 | 用途 | 前端是否有对应功能 | 前端入口 |
|----------|------|-------------------|----------|
| `ocr_recognize` | OCR识别图片 | ✅ 有 | 教师端 - 首页OCR上传 |
| `generate_questions` | AI生成练习题 | ✅ 有 | 教师端 - 题目管理 - AI出题 |
| `generate_variant` | 生成变式练习 | ✅ 有 | 学生端 - 错题本 - 变式练习 |
| `get_wrong_questions` | 获取错题列表 | ✅ 有 | 学生端 - 错题本 |
| `create_training` | 创建强化训练 | ✅ 有 | 学生端 - 错题本 - 开始训练 |
| `submit_training` | 提交训练结果 | ✅ 有 | 学生端 - 错题本 - 提交答案 |
| `get_review_tasks` | 获取复习任务 | ⚠️ 有但不明显 | 学生端 - 错题本（复习任务混在错题里） |
| `complete_review` | 完成复习 | ⚠️ 有但不明显 | 学生端 - 错题本（需优化入口） |
| `get_class_overview` | 班级学情概览 | ✅ 有 | 教师端 - 数据大盘 |
| `get_student_stats` | 学生学习统计 | ✅ 有 | 学生端 - 学习报告 |
| `trigger_warning_check` | 触发预警检测 | ⚠️ 有但需手动 | 教师端 - 学生管理（独立功能？） |
| `get_pending_warnings` | 获取待处理预警 | ⚠️ 有但不明显 | 教师端 - 学生管理 |
| `send_notification` | 发送通知 | ✅ 有 | 教师端 - 消息推送（未发现独立页面） |
| `diagnose_question` | 诊断障碍类型 | ✅ 有 | 教师端 - 障碍诊断 |
| `get_barrier_distribution` | 障碍分布统计 | ✅ 有 | 教师端 - 数据大盘 |
| `get_knowledge_heatmap` | 知识点热力图 | ✅ 有 | 教师端 - 数据大盘 |

### 4.4 Chat 对话界面（核心缺失）

**现状**：MCP 工具设计给 ChemAI Agent 用，但 Web 前端没有 chat 界面
**问题**：用户如何在 Web 端使用这些智能功能？

**两个解决方案**：

**方案A：接入 ChemAI Agent（推荐）**
```
Web前端 → ChemAI Agent (localhost:8642) → MCP → ChemAI后端
```
- 前端已有 `hermes.js` 服务
- 只需增加一个 Chat 界面
- ChemAI Agent 连接 Telegram/Discord 实现消息推送

**方案B：前端直连 MCP**
```
Web前端 → /api/mcp/call → ChemAI后端
```
- 不需要 ChemAI Agent
- 但失去 Agent 的智能调度能力
