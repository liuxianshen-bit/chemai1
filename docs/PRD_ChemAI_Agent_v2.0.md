## 1. Executive Summary

ChemAI Agent v2.0 是一款基于大语言模型的智能化学教学辅助系统，为化学老师和学生提供AI出题、障碍诊断、安全审核、学习改进等一体化服务。

**我们正在为**高中化学老师和学生们**构建**ChemAI Agent v2.0**，以解决**化学教学辅助工具缺乏专业化垂直能力**的问题，这将会**提升老师出题效率70%+，学生诊断准确率≥60%**。

## 2. Problem Statement

### Problem Framing Narrative

**I am:** 高中化学老师，10年教龄，日均课时4节，每周需要花2-3小时出练习题

**Trying to:**
- 高效生成符合教学要求的高质量化学练习题
- 精准诊断学生做题错误的原因和障碍类型
- 确保所出题目的化学方程式准确无误

**But:**
- 传统出题方式耗时较长，每次出套题要花2-3小时
- 难以判断学生错误的根本原因是概念不清、审题有误还是表述不规范
- 化学方程式安全审核依赖人工，容易出错

**Because:**
- 缺乏专业的AI工具来自动生成针对性的化学练习题
- 没有系统化的学生障碍诊断模型来区分不同障碍类型
- 没有四维安全审核机制来自动检查方程式

**Which makes me feel:**
- 时间被大量重复性工作占用，无法专注教学创新
- 对学生问题的判断依赖经验，缺乏系统性工具支持
- 担心题目中的方程式出错影响教学质量

### Final Problem Statement

高中化学老师需要一种方式**快速生成高质量化学练习题并自动诊断学生障碍**，因为当前出题耗时、障碍诊断缺乏系统性支持，这导致老师效率低下，学生也难以获得针对性的学习帮助。

## 5. Solution Overview

### High-Level Description

ChemAI Agent v2.0 提供六大核心功能：

1. **AI出题系统 (F1)**: 基于知识点和难度要求，AI自动生成高质量化学练习题，支持RAG增强和历年真题关联

2. **四维安全审核 (F2)**: 从系数平衡、条件完备、产物稳定性、分子结构四个维度自动审核化学方程式

3. **障碍诊断系统 (F3)**: 自动诊断学生障碍类型（概念理解型/审题障碍型/表述障碍型），生成针对性干预建议

4. **历年真题关联 (F4)**: 将练习题与中高考真题关联，增强实用性

5. **自进化改进系统 (F5)**: 基于老师反馈和学生数据，自动优化出题策略

6. **文档解析系统 (F6)**: 使用MinerU解析PDF/Word/图片格式的化学文档

### Key Features

| 功能 | 描述 | 优先级 |
|------|------|--------|
| F1.1 基础出题 | 根据知识点和难度生成题目 | P0 |
| F1.2 RAG增强 | 基于向量检索的历史题目关联 | P0 |
| F1.3 四维审核 | 系数/条件/产物/结构四维安全审核 | P0 |
| F2.1 障碍类型判断 | 自动判断学生障碍类型 | P0 |
| F2.2 干预建议生成 | 生成针对性教学建议 | P0 |
| F3.1 Prompt版本管理 | 管理Prompt版本和回滚 | P1 |
| F3.2 效果追踪 | 追踪改进措施的效果 | P1 |

## 7. User Stories & Requirements

### Epic Hypothesis

我们相信，为高中化学老师提供AI出题和障碍诊断功能，将会**提升老师出题效率70%+**，因为老师目前花费大量时间在重复性出题工作上，且缺乏系统性的学生障碍诊断工具。我们将衡量成功与否的标准是**出题时间和诊断准确率**。

---

### User Story 001: AI出题

- **Summary:** AI出题 - 老师输入知识点和难度，系统生成高质量练习题

**As a** 高中化学老师
**I want to** 输入知识点和难度要求，让AI自动生成练习题
**so that** 我可以快速获得符合要求的练习资源，不用花费2-3小时手动出题

#### Acceptance Criteria:
- **Scenario:** 老师输入"盐类水解"+"中等难度"+"10道题"，系统生成练习卷
- **Given:** 老师已登录系统
- **and Given:** 知识点"盐类水解"存在于知识库中
- **When:** 老师输入知识点"盐类水解"、难度"medium"、数量"10"
- **Then:** 系统在10秒内返回10道高质量练习题

---

### User Story 002: 四维安全审核

- **Summary:** 化学方程式四维审核 - 确保方程式准确无误

**As a** 系统
**I want to** 对生成的化学方程式进行四维安全审核
**so that** 学生不会学到错误的化学知识

#### Acceptance Criteria:
- **Scenario:** 系统审核化学方程式
- **Given:** 方程式"H2 + O2 → H2O"
- **When:** 调用四维审核API
- **Then:** 系统检出系数不平衡，返回修改建议"2H2 + O2 → 2H2O"

---

### User Story 003: 障碍类型诊断

- **Summary:** 诊断学生障碍类型 - 判断是概念理解、审题还是表述问题

**As a** 高中化学老师
**I want to** 输入学生的错误答题记录，获得障碍类型判断
**so that** 我能针对性地帮助学生克服学习障碍

#### Acceptance Criteria:
- **Scenario:** 老师提交学生答题记录进行诊断
- **Given:** 学生同一知识点连续错误3次
- **When:** 老师调用诊断API提交答题记录
- **Then:** 系统返回障碍类型"概念理解型"及干预建议

---

### User Story 004: 历年真题关联

- **Summary:** 练习题关联历年真题 - 增强实用性

**As a** 高中化学老师
**I want to** 查看练习题关联的历年真题
**so that** 我的练习更有针对性，学生备考更有效

#### Acceptance Criteria:
- **Scenario:** 查看练习题的真题关联
- **Given:** 练习题已生成
- **When:** 老师点击"关联真题"按钮
- **Then:** 系统显示关联的历年真题列表及相似度

---

### User Story 005: 自进化Prompt优化

- **Summary:** Prompt版本管理与回滚 - 支持策略调整

**As a** 系统管理员
**I want to** 修改Prompt后能立即生效，并支持回滚
**so that** 系统能持续优化，不用重启服务

#### Acceptance Criteria:
- **Scenario:** 管理员更新Prompt配置
- **Given:** 当前Prompt版本为v1.0
- **When:** 管理员提交新的Prompt内容
- **Then:** 新Prompt立即生效，版本更新为v1.1，支持一键回滚
