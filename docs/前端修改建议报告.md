## 二、历年真题的正确理解

### 2.1 历年真题的两个作用

根据用户说明，历年真题有两个作用：

**作用1: AI出题时的RAG参考**
- Agent调用`exam_search_historical`检索相似真题
- 基于真题生成变种题
- ✅ 现有版本已实现

**作用2: 老师手动选题加入试卷**
- 老师浏览历年真题列表
- 选择喜欢的题目直接加入当前试卷
- 早期版本有这个功能
- ❌ 现有版本缺失

### 2.2 上传真题的正确理解

**"上传真题"不是"上传说题"**，是从图片/PDF中识别题目并导入到真题库：

```
上传文件（图片/PDF）
    ↓
智能解析（OCR/MinerU/视觉模型自动选择）
    ↓
LLM格式化题目
    ↓
预览确认
    ↓
导入到真题集
```

这不是错题识别流程，而是**向题库导入新题目**的流程。

## 六、具体修改建议

### 6.1 考试管理页面 (`exam.js`)

#### 问题：只有考试CRUD，没有选题功能

**早期版本的交互**（需要移植）：

```
┌──────────────────────────────────────────────────────────────────┐
│  [AI生成题目]  [手动选题]  [导入真题]                              │
├──────────────────────────────────────────────────────────────────┤
│                                                                  │
│  【手动选题模式 - 三栏布局】                                        │
│  ┌────────────┬─────────────────────┬─────────────────┐         │
│  │ 筛选条件   │ 真题列表             │ 已选题目         │         │
│  │            │                     │                 │         │
│  │ 来源:全部  │ ┌─────────────────┐│ 共 0 题         │         │
│  │ 年份:全部  │ │ 2024长沙市一模  ││                 │         │
│  │ 知识点:全部│ │ 第1题: 氧化还原 ││ [选择题目卡片]   │         │
│  │ 难度:全部  │ │ 第2题: 离子反应 ││                 │         │
│  │            │ └─────────────────┘│ [清空] [加入]   │         │
│  └────────────┴─────────────────────┴─────────────────┘         │
└──────────────────────────────────────────────────────────────────┘
```

**建议修改**：

1. 新增Tab切换：AI生成 / 手动选题 / 导入真题
2. 手动选题模式：
   - 左栏：筛选（来源、年份、知识点、难度）
   - 中栏：真题列表（点击添加到右侧）
   - 右栏：已选题目列表
3. 导入真题模式：
   - 调用 `/api/ocr/parse/document` **智能解析文件**（自动选择 MinerU/OCR/视觉模型）
   - 调用 `/api/exam-bank/format-questions` 格式化题目
   - 预览确认后调用 `/api/exam-bank/import-questions` 导入

**智能解析策略**（与前面原定策略保持一致）：

| 文件类型 | 优先解析方式 | 降级策略 | 支持格式 |
|----------|--------------|----------|----------|
| PDF文档 | MinerU | 失败→返回错误 | `.pdf` |
| Word文档 | MinerU | 失败→返回错误 | `.docx` |
| 图片 | OCR | 失败→视觉模型 | `.jpg`, `.jpeg`, `.png`, `.gif`, `.bmp` |
| 复杂图片 | 视觉模型 | - | 模糊/倾斜/手写 |

**支持的批量导入格式**: `*.pdf`, `*.docx`, `*.png`, `*.jpg`, `*.jpeg`
