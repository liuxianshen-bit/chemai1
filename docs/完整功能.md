## 一、项目定位与架构

### 定位
面向高中化学教学的"AI + 数据分析"辅助系统，以"练习→诊断→复习→提高"为核心闭环。

### 用户角色
| 角色 | 入口 | 核心诉求 |
|------|------|---------|
| 系统管理员 | `teacher_v2.html` | 学校/班级/教师管理 |
| 学科组长 | `teacher_v2.html` | 教学分析、全校学情 |
| 任课教师 | `teacher_v2.html` | 出题、批改、诊断、报告 |
| 教务管理员 | `teacher_v2.html` | 考试安排、数据统计 |
| 学生 | `student_v2.html` | 练习、复习、报告、计划 |
| 家长 | `parent_portal.html` | 查看学生学情、接收通知 |

### 技术架构
```
前端 (HTML/CSS/JS + Vite)
  ├── ChemAI Agent 路径 →  AI 推理 (OCR/出题/诊断/报告)
  └── REST API 路径    →  数据 CRUD / 统计计算

后端 (FastAPI + SQLAlchemy + SQLite)
  ├── app/api/         ←  REST 端点 (24 个模块)
  ├── app/services/    ←  业务逻辑层 (14 个服务)
  ├── app/models/      ←  数据模型 (~20 张表)
  └── app/scheduler/   ←  定时任务

外部依赖:
  ├── 通义千问 LLM    ←  出题/诊断/计划生成
  ├── 智谱 GLM-OCR    ←  答题卡识别
  ├── Chrome/腾讯 OCR ←  OCR 备用
  ├── MinerU           ←  PDF/文档解析
  └── ChromaDB         ←  向量检索
```

## 六、缺失功能分析与建议

### 6.1 🔴 核心缺失（建议优先补充）

#### 1. AI 化学问答助手 (Chatbot)
- **现状：** 有 LLM 但只能用于出题和诊断，学生无法自由提问
- **建议：** 在学生端增加 AI 问答入口，通过 ChemAI Agent 实现
- **实现路径：** 新增 Hermes 工具 `chemistry_qa` → 学生输入问题 → LLM 回答 → 流式展示
- **复杂度：** 低（已有 LLM 集成，只需前端对话界面）

#### 2. 交互式元素周期表
- **现状：** 顶部装饰条不可交互
- **建议：** 开发完整的可交互周期表，点击元素显示：原子序数、原子量、电子排布、物化性质、常见化合价、相关知识点链接
- **实现路径：** 纯前端组件 + 元素数据 JSON
- **复杂度：** 中（数据量大但无后端依赖）

#### 3. 化学计算工具集合
- **现状：** 完全缺失
- **建议：** 开发以下计算器并嵌入学生端：
  - 摩尔质量计算器（输入化学式 → 自动计算）
  - 溶液浓度计算器（稀释/混合/质量分数/物质的量浓度）
  - pH 计算器（强酸/强碱/缓冲溶液）
  - 气体摩尔体积计算器
  - 化学平衡常数计算
  - 产率计算器
- **实现路径：** 后端新增 `app/api/calculator.py` 或作为前端纯计算工具
- **复杂度：** 中

#### 4. 知识点学习卡片 / 微课程
- **现状：** 只有题目，没有学习内容
- **建议：** 为每个知识点创建结构化的学习卡片（概念定义、公式、示例、常见误区、关联题目）
- **实现路径：** 新增数据表 + REST API + 前端卡片展示
- **复杂度：** 中（内容建设量大，MVP 可先覆盖 20 个高频考点）

---

### 6.2 🟡 重要补充（建议在核心缺失之后）

#### 5. 知识图谱可视化
- **现状：** `knowledge_graph.py` 已有 20 个考点数据，但无前端展示
- **建议：** 前端用量导向图 (D3.js/ECharts) 展示知识点关联，点击节点跳转学习卡片
- **实现路径：** 纯前端组件 + 后端提供图谱数据 API
- **复杂度：** 中

#### 6. 化学方程式库
- **现状：** 方程式审核有但无集中浏览
- **建议：** 建立常见化学反应方程式库（按反应类型分类：化合/分解/置换/复分解/氧化还原/离子反应），支持搜索和筛选
- **实现路径：** 新增数据表 + REST API + 前端浏览页
- **复杂度：** 低

#### 7. 有机化学结构式展示
- **现状：** 无任何结构式功能
- **建议：** 集成 Ketcher/RDKit.js 等结构式编辑器，支持学生绘制和提交结构式答案
