## 二、详细设计

### 1. LMS集成配置页面

**文件**: `teacher_v2.html` - 新增Tab `integration`

**功能点**:
- 钉钉/企业微信连接配置
- Webhook地址配置
- LTI 1.3 Provider配置
- API密钥管理（生成/查看/删除）
- SFTP配置（主机/用户名/密码/路径）

**API端点**:
```
GET    /api/integration/config           # 获取LMS配置
POST   /api/integration/config            # 保存LMS配置
POST   /api/integration/webhook/test     # 测试Webhook
POST   /api/integration/lti/links       # 获取LTI深度链接
GET    /api/integration/keys             # 获取API密钥列表
POST   /api/integration/keys            # 创建API密钥
DELETE /api/integration/keys/{key_id}    # 删除API密钥
GET    /api/integration/sftp/status      # SFTP状态
POST   /api/integration/sftp/config      # 配置SFTP
```

**UI布局**:
```
┌─────────────────────────────────────────────────────────────┐
│  系统集成                                                    │
├─────────────────────────────────────────────────────────────┤

├─────────────────────────────────────────────────────────────┤

│  └─────────────────────────────────────────────────────┘   │

└─────────────────────────────────────────────────────────────┘
```

### 3. 通知发送页面

## 三、实施顺序

### Phase 1: 核心流程补全（影响主要功能）

1. **学生端通知Tab** - 让学生能收到预警和通知
2. **通知发送页面** - 让教师能发送通知
3. **预警中心页面** - 让教师能处理预警

### Phase 2: 系统集成补全

4. **LMS集成页面** - 接入钉钉/企业微信
5. **操作日志页面** - 记录关键操作

### Phase 3: 体验优化

6. **复习中心独立Tab** - 复习任务独立入口
7. **学情记忆查看** - 查看学生知识点历史
