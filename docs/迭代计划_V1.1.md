# ChemAI V1.1 迭代计划

## 迭代目标

在V1.0的基础上，**完善学生自主学习闭环**和**增强家校互通能力**，实现从"被动诊断"到"主动干预"的升级。

## V1.1 迭代内容

### P0 - 必须实现（主动学习闭环）

#### P0-1: 每日练习自动推送机制

**问题**: 当前学生需要手动查看练习，缺少主动提醒

**实现方案**:
```
后端:
├── app/scheduler/daily_practice.py    # 定时任务模块
├── app/api/notification.py            # 增强通知API
└── 集成 APScheduler 或 FastAPI-CRON

前端:
└── student_v2.html 增加:
    ├── 消息中心入口(顶部铃铛图标)
    ├── 未读消息数量角标
    └── 消息列表页面
```

**双端考虑**:
- **学生端(移动端优先)**: 消息中心 + 端内通知 + 可选微信/短信推送
- **教师端(PC端优先)**: 后台任务管理 + 历史推送记录

**验收标准**:
- [ ] 每日8:00自动检测并推送练习任务
- [ ] 学生端收到消息通知
- [ ] 推送记录可查询

---

#### P0-2: 实时学情预警系统

**问题**: 教师需要手动查看报表才能发现学情问题

**实现方案**:
```
触发条件:
├── 连续3天未登录 → 提醒学生 + 通知教师
├── 成绩下滑10%以上 → 预警通知教师 + 建议干预
├── 错题超阈值(>50%) → 重点关注标记
└── 新障碍类型出现 → 及时诊断

后端:
├── app/services/early_warning.py      # 预警服务
├── app/api/warning.py                  # 预警API
└── app/models/warning_log.py           # 预警日志表

前端(教师端):
├── teacher_v2.html 增加:
│   ├── 预警中心图标(红色角标)
│   ├── 预警列表页面
│   └── 预警处理(已读/忽略/处理)
```

**双端考虑**:
- **学生端**: 收到"连续未学习"提醒，不显示给他人
- **教师端**: 预警仪表盘，班级学情一目了然

**验收标准**:
- [ ] 触发预警时教师端实时收到通知
- [ ] 预警列表显示历史预警
- [ ] 预警可标记处理状态

---

#### P0-3: 间隔重复复习系统

**问题**: 错题本只有列表，缺少基于遗忘曲线的复习安排

**实现方案**:
```
艾宾浩斯遗忘曲线复习节点:
├── 第1天复习: 当日错题
├── 第3天复习: 3天前错题(仍错误)
├── 第7天复习: 7天前错题(仍错误)
├── 第14天复习: 14天前错题(仍错误)
└── 第30天复习: 30天前错题(仍错误)

后端新增:
├── app/services/spaced_repetition.py   # 间隔重复服务
├── app/api/review.py                   # 复习任务API
├── app/models/review_task.py           # 复习任务表
└── 定时任务每日生成复习计划

前端(学生端):
├── practice.js 增加:
│   ├── "待复习"标签页
│   ├── 复习任务卡片
│   ├── 复习状态(已复习/待复习)
│   └── 复习效果反馈
```

**双端考虑**:
- **学生端(移动端)**: 复习任务作为独立Tab，支持碎片化学习
- **教师端**: 查看班级复习完成率

**验收标准**:
- [ ] 系统自动生成复习任务
- [ ] 学生端显示"待复习"题目
- [ ] 复习后标记状态更新

### P1 - 重要功能（增强体验）

#### P1-1: 教师智能出题系统

**问题**: 当前练习需要手动选题或随机出题

**实现方案**:
```
功能:
├── 根据班级薄弱知识点自动生成练习
├── 支持指定知识点、难度、题量
├── 生成后可直接布置或预览
└── 与现有考试记录系统集成

后端:
├── app/services/question_generator.py  # 智能出题服务
├── app/api/question_generate.py         # 出题API
└── 集成 LLM 服务

前端(教师端):
├── exam.js 增加:
│   ├── "智能出题"按钮
│   ├── 出题参数设置(知识点/难度/题量)
│   ├── 预览生成的题目
│   └── 一键布置作业
```

**双端考虑**:
- **教师端(PC端为主)**: 复杂参数设置和大屏预览
- **学生端**: 仅接收和完成练习

**验收标准**:
- [ ] 教师选择知识点生成练习
- [ ] 生成题目可编辑调整
- [ ] 布置后学生端可见

---

#### P1-2: 家长通知系统

**问题**: 家长无法及时了解学生学习情况

**实现方案**:
```
通知类型:
├── 每周学习简报(周五发送)
├── 重大考试成绩通知
├── 学情异常预警
└── 学习计划完成提醒

后端:
├── app/api/parent_notification.py      # 家长通知API
├── app/services/weekly_report.py       # 周报生成服务
└── 集成现有 chemistry_notification

前端:
├── 新增 parent_portal.html            # 家长端(移动端优先)
└── 功能:
    ├── 子女绑定(扫码/手机号)
    ├── 周报查看
    ├── 成绩通知列表
    └── 消息中心
```

**双端考虑**:
- **家长端(移动端)**: 独立HTML，轻量级查看
- **教师端**: 发送通知、查看发送记录
- **学生端**: 家长绑定确认

**验收标准**:
- [ ] 家长可通过链接访问
- [ ] 收到周报和成绩通知
- [ ] 家长可查看子女学习概况

#### P1-3: 学习进度追踪仪表盘

**问题**: 学生缺少直观的学习进度感知

**实现方案**:
```
功能:
├── 每日学习时长统计
├── 知识点掌握进度
├── 练习完成率趋势
├── 连续学习天数
└── 学习目标完成度

后端:
├── app/api/progress.py                 # 进度API
├── app/models/learning_log.py           # 学习日志表
└── 定时更新统计数据

前端(学生端):
├── student_v2.html 增加:
│   ├── 首页"学习进度"卡片
│   ├── 进度详情页面
│   ├── 成就徽章系统
│   └── 目标设定
```

**双端考虑**:
- **学生端(移动端)**: 进度卡片 + 成就系统激励
- **教师端**: 班级学习热力图

**验收标准**:
- [ ] 首页显示学习进度卡片
- [ ] 连续学习天数正确统计
- [ ] 知识点掌握可视化

#### P1-4: 错题强化训练

**问题**: 错题本只有"标记已掌握"功能，缺少针对性练习

**实现方案**:
```
功能:
├── 针对错题生成类似题目
├── 举一反三训练
├── 变式练习
└── 强化巩固

后端:
├── app/services/wrong_question_trainer.py  # 强化训练服务
├── app/api/practice/wrong_topic.py          # 错题练习API
└── 基于相同知识点的题目推荐

前端(学生端):
├── wrong.js 增强:
│   ├── "强化练习"按钮
│   ├── 针对该知识点的练习题
│   ├── 练习结果分析
│   └── 进步展示
```

**双端考虑**:
- **学生端(移动端)**: 错题详情页直接进入强化练习
- **教师端**: 可指定班级薄弱点统一训练

**验收标准**:
- [ ] 错题可发起强化练习
- [ ] 生成同知识点变式题
- [ ] 练习后更新掌握状态
