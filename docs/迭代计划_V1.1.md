# ChemAI V1.1 迭代计划

## 迭代目标

在V1.0的基础上，**完善学生自主学习闭环**、**增强家校互通能力**、**提升系统可观测性**，实现从"被动诊断"到"主动干预"的升级。

---

## 三端定位

| 端 | 定位 | 核心场景 |
|----|------|----------|
| **学生端** | 移动端优先 | 练习、复习、查看报告、学习任务 |
| **教师端** | PC端优先 | OCR上传、班级管理、学情诊断、智能出题 |
| **家长端** | 移动端优先 | 查看周报、成绩通知、绑定子女 |

## V1.1 迭代内容

### P0 - 必须实现（主动学习闭环）

#### P0-1: 每日练习自动推送机制

**问题**: 学生需要手动查看练习，缺少主动提醒

**三端考虑**:
- **学生端**: 消息中心 + 端内通知 + 可选微信/短信推送
- **教师端**: 后台任务管理 + 历史推送记录
- **家长端**: 子女练习完成情况推送

```
后端:
├── app/scheduler/daily_practice.py    # 定时任务
├── app/api/notification.py           # 通知API
└── 集成APScheduler

前端:
├── student_v2.html: 消息中心入口、消息列表
├── teacher_v2.html: 推送记录管理
└── parent_portal.html: 子女完成情况
```

**验收标准**:
- [ ] 每日8:00自动推送练习任务
- [ ] 三端均可收到/查看通知
- [ ] 推送记录可查询追溯

---

#### P0-2: 间隔重复复习系统

**问题**: 错题本只有列表，缺少基于遗忘曲线的复习安排

**艾宾浩斯复习节点**: 1天 → 3天 → 7天 → 14天 → 30天

**三端考虑**:
- **学生端**: 复习任务Tab，支持碎片化学习
- **教师端**: 班级复习完成率看板
- **家长端**: 子女复习提醒

```
后端:
├── app/services/spaced_repetition.py  # 间隔重复引擎
├── app/api/review.py                 # 复习任务API
└── app/models/review_task.py         # 复习任务表

前端:
├── student_v2.html: "待复习"Tab、复习卡片
├── teacher_v2.html: 班级复习完成率
└── parent_portal.html: 复习提醒
```

**验收标准**:
- [ ] 系统按遗忘曲线生成复习任务
- [ ] 学生端显示待复习题目
- [ ] 复习后状态更新

---

#### P0-3: 实时学情预警系统

**问题**: 教师需要手动查看报表才能发现问题

**触发条件**:
- 连续3天未登录 → 学生+教师+家长通知
- 成绩下滑>10% → 教师预警
- 错题率>50% → 重点关注标记
- 新障碍类型出现 → 及时诊断

**三端考虑**:
- **学生端**: 收到"连续未学习"提醒（不显示给其他人）
- **教师端**: 预警仪表盘，班级学情一目了然
- **家长端**: 子女异常预警通知

```
后端:
├── app/services/early_warning.py      # 预警服务
├── app/api/warning.py               # 预警API
└── app/models/warning_log.py        # 预警日志

前端:
├── teacher_v2.html: 预警中心(红色角标)、预警列表、处理功能
├── student_v2.html: 学习提醒通知
└── parent_portal.html: 子女异常提醒
```

**验收标准**:
- [ ] 预警触发时三端同步通知
- [ ] 预警列表显示历史记录
- [ ] 预警可标记处理状态

### P1 - 重要功能（增强体验）

#### P1-1: 教师智能出题系统

**问题**: 当前练习需要手动选题

**三端考虑**:
- **教师端**: 复杂参数设置、大屏预览、批量布置
- **学生端**: 仅接收和完成练习
- **家长端**: 查看教师布置的练习内容

```
后端:
├── app/services/question_generator.py  # 智能出题服务
├── app/api/question_generate.py         # 出题API
└── 集成LLM服务

前端:
├── teacher_v2.html: 智能出题入口、参数设置、预览、布置
├── student_v2.html: 接收并完成练习
└── parent_portal.html: 查看布置的练习
```

**验收标准**:
- [ ] 教师选择知识点生成练习
- [ ] 题目可编辑调整
- [ ] 布置后学生端可见

---

#### P1-2: 错题强化训练

**问题**: 错题本只有"标记已掌握"，缺少针对性练习

**三端考虑**:
- **学生端**: 错题详情页直接进入强化练习
- **教师端**: 可指定班级薄弱点统一训练
- **家长端**: 子女强化练习进度

```
后端:
├── app/services/wrong_question_trainer.py  # 强化训练服务
└── app/api/practice/wrong_topic.py          # 错题练习API

前端:
├── wrong.js: "强化练习"按钮、变式练习、效果反馈
├── teacher_v2.html: 薄弱点统一训练
└── parent_portal.html: 练习进度
```

**验收标准**:
- [ ] 错题可发起强化练习
- [ ] 生成同知识点变式题
- [ ] 练习后更新掌握状态

### P2 - 锦上添花（完整生态）

#### P2-1: 家长端APP/通知系统

**问题**: 家长无法及时了解子女学习情况

**通知类型**:
- 每周学习简报（周五发送）
- 重大考试成绩通知
- 学情异常预警
- 学习计划完成提醒
- 教师留言/私信

**三端考虑**:
- **家长端(移动端)**: 独立HTML，扫码即用，极简风格
- **教师端**: 发送通知、查看发送记录、家长管理
- **学生端**: 家长绑定确认

```
后端:
├── app/api/parent_notification.py    # 家长通知API
├── app/api/parent_binding.py          # 亲子绑定API
├── app/services/weekly_report.py     # 周报生成服务
└── app/services/parent_portal.py     # 家长端服务

前端:
├── parent_portal.html (新):          # 家长端(移动端优先)
│   ├── 子女绑定(扫码/手机号)
│   ├── 学习周报查看
│   ├── 成绩通知列表
│   ├── 消息中心
│   └── 子女学习概况
├── teacher_v2.html:                  # 增加家长管理、发送通知
└── student_v2.html:                  # 增加家长绑定入口
```

**验收标准**:
- [ ] 家长可通过链接/二维码访问
- [ ] 收到周报和成绩通知
- [ ] 可查看子女学习概况
- [ ] 教师可管理家长信息

```
数据维度:

**验收标准**:
- [ ] 教师端有完整数据大盘

└── teacher_v2.html: 集成设置页面
```

- [ ] 提供标准API文档
