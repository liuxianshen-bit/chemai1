## 一、产品概述

### 1.1 什么是 ChemAI Agent

ChemAI Agent 是一款面向高中化学教师和学生的 **AI Agent 驱动** 智能教学工具。它不是传统的 SaaS 软件，而是一个具备**自主思考、自主决策、自主执行**能力的化学教学 Agent 系统。

**核心区别：**

| 维度 | 传统教学软件 | ChemAI Agent |
|------|-------------|--------------|
| 交互方式 | 菜单点击 → API调用 → 返回结果 | 自然语言指令 → Agent理解 → 自主规划 → 执行 → 反馈 |
| 出题能力 | 固定模板选题 | 全题型生成（选择/填空/问答/计算）+ 历年真题智能提取 |
| 审核方式 | AI 单独审核 | **AI 预审 + 人工二审** 双层保障 |
| 学习进化 | 无 | 从教学数据中学习，优化选题策略 |
| 多端推送 | 手动发送 | Agent 自动推送（微信/钉钉/邮件） |
| 障碍诊断 | 规则匹配 | Agent 推理 + 知识点关联分析 |

#### 2.2.2 化学式处理（关键差异点）

**传统方案的问题：**
- LLM 生成化学式靠文本：`H2O`、`Fe2O3`、`Ca(OH)2`
- 上下标丢失，显示不规范
- 容易混淆：`Fe2O3` vs `FeO` vs `Fe3O4`

**ChemAI Agent 的方案：**
```
LLM 生成 → LaTeX 标准化 → 化学方程式配平校验 → 人工确认 → 入库
           ↓
        H_2O（标准格式）
        \rightarrow（反应箭头）
        Ca^{2+}（离子标注）
        \ Equilibrium（可逆反应）
```

**MinerU 的价值：**
- 从历年真题 PDF 中提取的题目，化学式自动转为标准 LaTeX
- 图片中的化学式（如分子结构图）也能识别为 LaTeX

| 维度 | 传统手动录入 | MinerU 智能提取 |
|------|-------------|----------------|
| **录入方式** | 人工逐题输入 | PDF 一键解析 |

| **化学式** | 需人工转换 LaTeX | 自动识别转为 LaTeX |
| **知识点** | 人工标注 | AI 自动关联知识图谱 |
| **工作量** | 1道题 ~5分钟 | 1份试卷 ~2分钟 |
| **覆盖率** | 有限题库 | **历年高考题全覆盖** |

### 3.3 MinerU 集成方式

```python
# 调用 MinerU 解析历年真题 PDF
from mineru.cli import api_client as mineru_client

async def parse_exam_pdf(file_path: str):
    """使用 MinerU 解析试卷 PDF"""
    form_data = mineru_client.build_parse_request_form_data(
        lang_list=["ch"],
        backend="hybrid-auto-engine",  # 推荐后端，高精度
        parse_method="auto",
        formula_enable=True,   # 关键：启用公式识别
        table_enable=True,
    )
    # 提交任务并等待结果
    result = await mineru_client.submit_and_wait(file_path, form_data)
    return result
```

## 五、产品亮点总结

### 5.1 六大核心亮点

| # | 亮点 | 差异化价值 | 技术支撑 |
|---|------|-----------|---------|
| 1 | **全题型 AI 出题** | 支持填空/问答/计算，不止选择题 | Prompt 工程 + LaTeX 校验 |
| 2 | **历届真题智能提取** | PDF 一键解析，无需手动录入 | MinerU 公式识别 + LaTeX 转换 |
| 3 | **四维安全审核** | AI 预审 + 人工二审，双重保障 | 化学方程式配平零错误 |
| 4 | **学生障碍精准诊断** | 概念/审题/表述三类，个性化干预 | Hermes 推理 + 知识点图谱 |
| 5 | **Agent 自进化** | 从教学数据中学习，优化选题 | Hermes 记忆 + 指标分析 |
| 6 | **多端即时推送** | 微信/钉钉/邮件全自动 | Hermes 消息网关集成 |

### 5.2 对比传统产品

| 维度 | 传统网校/教辅App | ChemAI Agent |
|------|-----------------|--------------|
| **智能化程度** | 规则引擎，固定模板 | Agent 自主决策，动态调整 |
| **题型覆盖** | 以选择题为主 | **全题型**（+填空/问答/计算）|
| **化学式处理** | 文本格式，错误率高 | **LaTeX 标准化**，MinerU 识别 |
| **历年真题** | 需人工录入，覆盖有限 | **PDF 智能提取**，覆盖完整 |
| **学习进化** | 无 | **数据驱动**，策略自动优化 |
| **审核机制** | AI 单独审核 | **AI + 人工双审**，质量保障 |
| **部署成本** | ¥5000+/月 | **¥300/月**，性价比极高 |
