## 3. 第1周: 基础架构重构

### 目标: 建立可维护的前端架构

### 任务清单

| 任务 | 工作内容 | 交付物 | 负责人 |
|------|----------|--------|--------|
| T1.1 | 拆分teacher.html | 分离CSS/JS到独立文件 | 前端 |
| T1.2 | 创建项目结构 | 建立src/components, src/pages, src/services | 前端 |
| T1.3 | 引入构建工具 | Vite配置 | 前端 |
| T1.4 | 建立API服务层 | api/ 目录，封装所有API调用 | 前端 |
| T1.5 | 统一错误处理 | 全局API拦截器 | 前端 |

### 交付物

```
frontend/
├── src/
│   ├── api/
│   │   ├── index.js          # API入口
│   │   ├── exam.js          # 考试相关API
│   │   ├── question.js       # 题目相关API
│   │   ├── diagnosis.js      # 诊断相关API
│   │   ├── practice.js       # 练习相关API
│   │   └── auth.js           # 认证API
│   ├── components/           # 通用组件
│   ├── pages/               # 页面组件
│   ├── styles/              # 样式文件
│   └── utils/               # 工具函数
├── index.html
├── vite.config.js
└── package.json
```

### 验收标准

- [ ] teacher.html从334KB拆分为<50KB
- [ ] 所有API调用通过统一服务层
- [ ] Vite构建工具可正常运行
- [ ] 错误拦截器捕获所有API错误

## 4. 第2周: 核心业务对接

### 目标: 完成核心功能API对接

### 任务清单

| 任务 | 工作内容 | 交付物 | 优先级 |
|------|----------|--------|--------|
| T2.1 | 教师端考试模块 | initExamModule()完整实现 | P0 |
| T2.2 | 教师端题目模块 | initQuestionModule()完整实现 | P0 |
| T2.3 | 教师端诊断模块 | initDiagnosisModule()完整实现 | P0 |
| T2.4 | 学生端练习流程 | 完整练习->提交->结果流程 | P0 |
| T2.5 | 学生端障碍诊断 | 展示诊断结果和建议 | P0 |

### API对接清单

| 模块 | API端点 | 状态 | 说明 |
|------|---------|------|------|
| 考试 | POST /api/exam/create | 待对接 | 创建考试 |
| 考试 | GET /api/exam/list/{class_id} | 待对接 | 考试列表 |
| 题目 | POST /api/question/generate | 待对接 | AI生成题目 |
| 题目 | POST /api/question/audit | 待对接 | 题目审核 |
| 诊断 | GET /api/diagnosis/barrier/{class_id}/{exam_id} | 待对接 | 障碍诊断 |
| 练习 | POST /api/practice/submit | 待对接 | 提交练习 |

### 验收标准

- [ ] 教师可创建考试并选择题目
- [ ] AI出题API可调用并显示结果
- [ ] 障碍诊断结果正确展示
- [ ] 学生可完成完整练习流程
