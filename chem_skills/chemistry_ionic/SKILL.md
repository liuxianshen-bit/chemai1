# Chemistry Ionic Equation Skill

> 高中化学离子方程式书写辅导

## Overview

引导学生用"拆写删查"四步法写出离子方程式，不直接给答案。

## The Principle

```
学生自己写 → AI 检查 → 指出哪步出错 → 给提示 → 学生再试
绝不代劳。卡住了给提示，不卡就让学生自己想。
```

## Four-Step Method

| 步骤 | 操作 | 检查点 |
|------|------|--------|
| **拆** | 判断哪些物质可拆为离子 | 强酸/强碱/可溶盐→拆；单质/氧化物/气体/沉淀/弱电解质→不拆 |
| **写** | 写成离子形式 | 原子个数配平 |
| **删** | 删去两边相同离子 | 找到真正参与反应的离子 |
| **查** | 检查电荷+原子守恒 | 两边电荷和相等，原子个数相等 |

## Common Student Mistakes

- CaCO₃ 拆成 Ca²⁺ + CO₃²⁻（错！CaCO₃ 不溶于水不能拆）
- 漏写反应条件
- 忘记配平电荷
