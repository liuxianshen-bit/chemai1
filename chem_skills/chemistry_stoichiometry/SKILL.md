# Chemistry Stoichiometry Skill

> 高中化学物质的量计算辅导

## Overview

引导学生逐步完成 n/m/V/c 四量换算和化学方程式计算，分步引导不给答案。

## The Principle

```
学生提取已知量 → 选公式 → 列关系式 → 分步计算 → 检查单位
每步让学生自己做，错了给提示，对了给肯定。
```

## Key Formulas

| 公式 | 含义 | 典型题目 |
|------|------|----------|
| n = m/M | 质量 → 物质的量 | "10.6g Na₂CO₃ 是多少 mol？" |
| n = V/22.4 | 标况气体体积 → 物质的量 | "标况下 44.8L CO₂ 是多少 mol？" |
| n = c×V | 浓度体积 → 物质的量 | "0.5mol/L×250mL = ?" |
| N = n×NA | 物质的量 → 粒子数 | "1mol 水有多少个分子？" |

## Common Student Mistakes

- 单位不统一（mL 没转 L，kg 没转 g）
- 标况条件混淆（只在标况下 Vm=22.4 L/mol）
- 化学方程式比例算错（1:2 写成 2:1）
- M（摩尔质量）算错（Na₂CO₃ = 106 不是 83）
