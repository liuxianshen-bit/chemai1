```
│ 🤖 AI助手  │  ┌── 对话消息 ────────────────────┐  │

│            │  └────────────────────────────────┘  │
│            │  ┌── 快捷提问 ───────────────────┐  │
│            │  │ [配平] [出题] [实验] [概念]    │  │
│            │  │ [查真题] [诊断]               │  │
│            │  └────────────────────────────────┘  │
```

**AI 回复优化（参考 Pensieve Grader 的反馈模式）：**
- 工具调用时立即显示 ToolCard（不需要等回复）→ 消除"卡顿感"
- 添加 typing indicator 动画（三个点跳动）
- 思考过程可折叠展开（参考纸鸢AI的ThinkingBubble）

**Agent 性能优化：**
- `run_stream()` 现在做两次 LLM 调用（Think + Reply），Think 阶段只发 phase 事件不阻塞
- 直接回复（无工具调用）场景优化为一次调用 + 流式输出

### 2.3 答题卡识别 `/ocr`

**流程（参考 Pensieve Grader 的 OCR 评分流程）：**

```
选班级 → 上传答题卡 → AI 识别 → 预览结果（含置信度标记）
                                           ↓
                              高置信度: 绿色 ✅ 自动接受
                              低置信度: 橙色 ⚠️ 需人工确认
                              识别失败: 红色 ❌ 手动录入
                                           ↓
                              人工修正 → 确认入库 → 自动生成错题统计
```

**关键交互：**
- 上传后显示进度条（每张答题卡的识别状态）
- 结果预览表格：可点击单元格编辑答案
- 低置信度项高亮显示
- 入库后快捷入口：「查看错题报告」

**三个 Tab：**

```
├────────────────────────────────────────────┤

│ │ 第一次月考 | 高一(1)班 | 15题 | 未发布  │   │
│ │ [编辑题目] [预览] [发布] [删除]        │   │
│ │ ────────────────────────────────      │   │
│ │ 期中考试 | 高一(1)班 | 20题 | 已发布    │   │
│ │ 完成率: 34/34 | 均分: 78.5            │   │
│ │ [查看结果] [查看报告]                  │   │
│ └──────────────────────────────────────┘   │
│                                            │
│ Tab 2: 题库                                 │
│ [AI 出题] [手动录入] [从真题导入]            │
│ ┌── 我的题目列表 ──────────────────────┐   │
│ │ 题目内容... | 知识点 | 难度 | 审核状态 │   │
│ │ [编辑] [删除] [添加到考试]            │   │
│ └──────────────────────────────────────┘   │
│                                            │
│ Tab 3: 历史真题                             │
│ [搜索框] [年份▼] [难度▼] [知识点▼]          │
│ ┌── 真题列表 (250题) ──────────────────┐   │
│ │ 湖南卷2025 T1 | 金属材料 | easy        │   │
│ │ [查看详情] [添加到题库]               │   │
│ └──────────────────────────────────────┘   │
└────────────────────────────────────────────┘
```

**创建考试完整流程：**

1. 填写考试名称 + 选择班级
2. 添加题目（三种来源）：
   - 「AI 出题」：选知识点 + 难度 + 数量 → LLM 生成 → 预览 → 批量添加到考试
   - 「题库选取」：从我的题目列表勾选
   - 「真题导入」：从历史真题勾选
3. 预览考试（展示题目列表 + 每题审核状态）
4. 发布 → 学生端收到练习任务

**关键交互：**
- 拖拽调整题目顺序
- 每题右上角显示配平审核状态（✅/⚠️/❌）
- 发布前弹窗确认：「发布后学生将立即收到练习任务，确认发布？」

### 2.5 障碍诊断 `/diagnosis`

**流程（参考 ChemBuddy 的多 Agent 诊断模式）：**

```
选班级 → 选考试 → 开始诊断
    ↓
 诊断结果
 ├── 班级概览（三种障碍分布饼图 + 人数）
 ├── 需关注学生列表（按障碍严重度排序）
 │     └── 点击学生 → 展开详细诊断
 │           ├── 障碍类型 + 置信度
 │           ├── 薄弱知识点列表
 │           ├── 推荐干预策略
 │           └── [生成学习计划] [查看已生成计划]
 └── 知识点维度（哪个知识点错误率最高）
```

**学习计划管理（不是"生成完就没了"）：**
- 点击「生成学习计划」→ 显示生成中的 loading → 生成完成 → 自动展开计划内容
- 已生成的计划存为卡片，可随时查看/编辑/删除
- 计划包含：周期、每日任务、资源推荐、鼓励语
- [应用计划] → 学生端可见
- [发给家长] → 家长端收到通知

## 三、Agent 性能问题修复

**问题诊断：** `core.py` 的 `run_stream()` 在工具调用场景下：
1. 先发 Think → 等 LLM 决定用哪个工具（~2-3秒）
2. 执行工具（~0.3秒）
3. 再发 Reply → 等 LLM 生成回复（~3-5秒）
4. 前端在 Think 和 Reply 之间没有任何反馈

**修复方案：**
1. Think 阶段立即 yield `phase: thinking` + `tool_call` 事件 → 前端立即显示 ToolCard
2. 工具执行完成后 yield `tool_result` → 前端更新 ToolCard
3. Reply 阶段流式输出 → 前端逐字显示
4. 全程 StatusBar 显示当前阶段 + 耗时

**没有工具调用的快速回复优化：**
1. 去掉 Think 阶段的非流式调用
2. 直接用 `chat_stream` 流式输出
3. 第一个 token 到达的时间从 ~3秒 降到 ~1秒

## 四、视觉还原要点

**Academic Catalyst 设计系统的关键细节必须实现：**

1. **侧边栏：** Oxford Blue (#002045) 背景，白色/蓝灰文字，选中的导航项白色加粗 + 右侧白色边框
2. **AI 气泡：** ai-glow (#E0F2F1) 背景 + glassmorphism（backdrop-filter: blur(12px)）+ 1px 青色边框
3. **用户气泡：** Oxford Blue 背景，白色文字，右下角是直角
4. **ToolCard：** 左侧 surface-tint (#455f88) 3px 边线，可折叠，JetBrains Mono 字体
5. **卡片：** 白色背景 + 1px wood-accent 边框（30% opacity），hover 时微阴影
6. **表格：** JetBrains Mono 表头（11px uppercase），IBM Plex Sans 正文
7. **进度条：** primary→secondary 渐变填充 + 脉冲动画
8. **按钮：** Oxford Blue 主按钮，Deep Teal 辅助按钮，hover 时加深
9. **搜索/筛选：** 内嵌样式输入框，focus 时 2px Oxford Blue 边框 + 外发光
10. **Modal：** 16px 圆角，柔和大阴影，backdrop 模糊
