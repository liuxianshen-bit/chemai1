# 智辅化学 — 教师端原型规格

## 角色：高中化学教师（李老师）
李老师教高二化学，带两个班共67名学生。每周要改卷、出题、分析学情。

---

## 页面1：登录页

**布局：** 居中卡片，暖色学术风格背景

**元素：**
- 标题：「智辅化学 ChemAI」
- 用户名输入框（placeholder: 手机号/用户名）
- 密码输入框（placeholder: 密码）
- 角色选择下拉框（教师/学生/家长）
- 登录按钮（主色调，圆角）
- 底部：「还没有账号？申请入驻」

**交互：**
- 点击登录 → 验证成功 → 跳转首页
- 点击「申请入驻」→ 弹出教师入驻表单（姓名/手机号/学校/学科/教师资格证上传）

---

### 元素清单

**侧边栏：**
- 「💬 新对话」按钮 → 清空当前对话，开始新会话
- 功能菜单（7项，点击切换页面）：
  - 📷 答题卡识别 → 页面3
  - 📝 考试管理 → 页面4
  - 📊 题目管理 → 页面5
  - 🩺 障碍诊断 → 页面6
  - 📈 学情报告 → 页面7
  - 🎯 学情面板 → 页面8
  - 🎓 学生管理 → 页面9

**对话消息区：**
- 用户消息气泡（右对齐，主色背景，白色文字）
- AI 消息气泡（左对齐，浅灰背景，深色文字，Markdown 渲染）
- 工具调用卡片（可折叠，左侧彩色边框，展示工具名 + 执行状态 + 结果摘要）
- 流式输出：AI 回复逐字显示

**快捷提问栏（6个芯片按钮，点击自动填入输入框并发送）：**
- ⚖️ 配平方程式（prompt: "帮我配平 Fe + O2 = Fe2O3"）
- 📝 出题练习（prompt: "出3道关于盐类水解的选择题"）
- 🔬 模拟实验（prompt: "模拟钠与水的反应实验"）
- 📖 讲解概念（prompt: "请讲解氧化还原反应的基本概念"）
- 🔍 查真题（prompt: "搜索关于化学平衡的高考真题"）
- 🩺 错题诊断（prompt: "分析班级最近的错题情况"）

**输入区：**
- 多行文本输入框（placeholder: "输入化学教学问题，Enter 发送，Shift+Enter 换行"）
- 发送按钮（主色调，输入为空时禁用）

**状态栏（底部，AI 处理时显示）：**
- 状态指示器（圆点闪烁动画）
- 文字：「思考中...」/「执行: balance_equation」/「回复中...」

### 创建考试流程

**第1步 — 基本信息：**
- 考试名称输入框
- 选择班级下拉框
- 考试日期选择器

**第2步 — 添加题目（三种方式切换 Tab）：**
- Tab1「AI 生成」：选知识点（多选标签）+ 难度（简单/中等/困难）+ 数量 → 点击「生成题目」
- Tab2「真题库」：搜索框 + 年份/知识点/难度筛选 → 题目列表（可多选勾选）
- Tab3「手动录入」：文本输入框 → 输入题目内容/选项/答案

**第3步 — 预览确认：**
- 题目列表预览（每题显示内容/选项/答案/审核状态）
- 方程式自动审核结果（通过 ✅ / 需修改 ⚠️ / 未通过 ❌）
- 「确认发布」按钮

**第4步 — 发布结果：**
- 成功提示
- 学生端自动收到练习任务

## AI 对话核心能力清单

教师在聊天框可以做的所有事：

| 输入示例 | AI 做什么 | 结果展示 |
|---------|----------|---------|
| "配平 Fe+O2=Fe2O3" | 调 balance_equation | 卡片显示左右元素计数 + 配平结果 |
| "出3道盐类水解选择题" | 调 generate_questions | 3道完整题目 + 选项 + 答案 + 审核状态 |
| "搜索化学平衡真题" | 调 search_exam_bank | 题目列表 + 年份/来源标注 |
| "分析三班电离平衡掌握情况" | 调 diagnose_barrier | 班级障碍分布 + 需关注学生 |
| "模拟钠与水反应实验" | 调 simulate_experiment | 实验步骤/现象/方程式/安全提醒 |
