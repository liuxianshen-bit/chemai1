# Proposal: production-readiness

## Summary

系统加固、性能优化、安全审核、对标 PRD v1.0 评测清单进行全模块功能/LLM/性能测试。

## Motivation

前面的 5 个 change 完成后，功能层面已经齐全。生产上线前还需要：
- 系统不会在边界条件下崩溃
- 性能达到 PRD 要求（P95 < 1s 等）
- LLM 输出质量通过验收标准（准确率 ≥85%，配平零错误等）
- 安全基线（认证、数据隔离、文件清理）

## Scope

- 系统加固：统一错误码、频率限制、文件安全、SQLite WAL
- 性能优化：缓存、懒加载
- 安全审核：认证完善、数据隔离验证
- 测试评测：F1-F7 全部测试用例 + LLM 质量评测 + 性能基准

## Dependencies

依赖前面 5 个 change 全部完成（这是最后一个 change）

## Acceptance

- [ ] P95 API 延迟满足 PRD 要求
- [ ] 化学方程式配平审核 100% 准确（10 用例全通过）
- [ ] LLM 出题成功生成率 ≥ 95%
- [ ] 认证/权限/数据隔离通过安全测试
- [ ] 服务连续运行 24h 无 crash
