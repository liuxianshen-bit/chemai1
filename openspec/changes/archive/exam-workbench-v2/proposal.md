# Proposal: exam-workbench-v2

## Summary

考试工作台交互重构：三Tab碎片化 → 左右分栏单页工作台。统一出题流程，消除反直觉操作。

## Motivation

基于竞品分析（Kahoot/Quizlet/Notion AI/猿题库）和实际操作体验，当前 exam.html 核心问题：

| 问题 | 现状 | 影响 |
|------|------|------|
| Tab 割裂 | 考试/题库/历史 三Tab独立 | 出一份卷子需跨三个Tab |
| AI出题藏弹窗 | 题库Tab → 点"AI出题" → 弹窗 | 看不到题库上下文 |
| 知识点输入原始 | 逗号分隔文本框 | 不知道有哪些知识点可选 |
| 保存反直觉 | 提示"请先在题库Tab创建文件夹" | 打断出题心流 |
| 双时代UI拼凑 | 审核按钮+保存按钮共存 | 操作混乱 |

## 竞品参考

- **Kahoot**: 左侧题型选择 → 右侧题目画布，所见即所得
- **Quizlet**: 表格式批量编辑，一键全部生成
- **Notion AI**: AI输出直接inline编辑
- **Dribbble QBank**: 文件夹树 + 题目列表双栏

├──────────┬───────────────────────────────────────┤

│ 题型     │  └──────────────────────────────────┘ │

│ 数量 [5] │                                       │

## Scope

- 新建 `pages/exam-v2.html` — Vue 3 单页应用
- 保留旧 `exam.html` / `exam.js` 为 .bak
- 侧边栏入口指向新页面

## Acceptance

- [ ] 单页左右分栏，无需Tab切换完成出题全流程
- [ ] 知识点chips + 题型chips在左侧直接可用
- [ ] 每题可编辑/保存/移除，保存后卡片状态变化
- [ ] 保存时文件夹dropdown可选或一键新建
- [ ] 三个题目来源切换: AI生成/手动录入/从题库选择
- [ ] 批量操作: 全部保存/全部删除/全部重出
